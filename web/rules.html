Rummikub Rules

Quick reference for classic Rummikub and this daily puzzle.

X

Classic Rummikub

Use tiles to form melds. Every tile must belong to a valid run or set.

  • Runs: same color, consecutive numbers, length 3 or more.
  • Sets: same number, 3 or 4 tiles, all different colors.
  • No jokers are used in this puzzle.
  • Each tile exists twice in the full set.

Daily Puzzle Rules

You are given a starting board and a set of required tiles.

  • Place every required tile onto the board.
  • Rearrange existing tiles to make all melds valid.
  • All tiles on the board must belong to valid melds.
  • Win when every tile is placed and every meld is valid.

Tips

  • Break runs into smaller parts to free tiles.
  • Use the workspace to plan before committing.
  • Look for shared numbers that can become sets.
